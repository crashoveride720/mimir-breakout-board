# Revision 1.0

## Status

Released

---

## Description

Revision 1.0 is the initial production release of the Mimir ESP32-S3 Carrier Board.

This revision successfully demonstrated the mechanical layout of the design, including:

- ESP32-S3 fitment
- CAN Bus module fitment
- MicroSD module fitment
- GPIO access
- USB-C accessibility
- MicroSD accessibility
- Mounting hole placement

Prototype assembly confirmed that the overall PCB layout functioned as designed.

---

## Known Issues

The selected 2.54 mm screw terminal blocks used larger terminal pins than anticipated.

The original PCB footprint specified **0.8 mm plated through-holes**, which accepted some manufacturers' terminal blocks but not others.

This issue does not affect board functionality and is corrected in Revision 1.2.
