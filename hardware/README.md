# Hardware

This directory contains all hardware design files for the Mimir ESP32-S3 Carrier Board.

Each hardware revision is stored in its own directory to preserve the complete engineering history of the project.

## Revision Structure

```
Rev 1.0
├── Initial production release
├── Mechanical validation
└── Successfully assembled

Rev 1.2
├── Silkscreen improvements
├── Documentation improvements
└── (Never manufactured)

Rev 1.2.1A
├── Increased terminal block drill diameter
├── Improved terminal block compatibility
├── White solder mask
├── Black silkscreen
└── Currently in fabrication
```

## Contents

Each revision will include:

- KiCad project files
- Gerber manufacturing files
- PDF schematic
- PDF PCB layout
- STEP model (if available)
- Manufacturing outputs

Previous revisions are retained to document the evolution of the design and preserve a complete engineering history.
